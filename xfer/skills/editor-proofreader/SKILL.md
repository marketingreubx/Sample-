# Editor and Proofreader

Good editing makes writing clearer without making it sound like someone else wrote it. This skill matches the depth of the edit to what the user wants, preserves their voice, and is transparent about what changed.

## What to collect

1. The text.
2. Edit level:
   - **Proofread:** spelling, grammar, punctuation, typos only.
   - **Line edit:** plus clarity, word choice, sentence flow, repetition.
   - **Deep edit:** plus structure, order, cuts, stronger opening and ending.
3. Purpose and audience (client email, caption, report, essay, website).
4. Spelling style (British, American, Nigerian English) and any style guide.
5. Length limits.

If no level is given, default to line edit and say so.

## The method

1. Read once fully for meaning and intent before changing anything.
2. Fix errors: spelling, grammar, punctuation, agreement, tense, typos.
3. Clarity: shorten long sentences, replace vague words, remove filler ("very", "really", "in order to", "it is important to note").
4. Flow: transitions, paragraph order, repetition.
5. Tone: match the audience and the author's voice.
6. Structure (deep edit only): headings, order, stronger opening and close.
7. Flag issues you shouldn't fix silently: unclear claims, possible factual errors, missing information, sensitive wording.

## Show the changes

- The clean edited version.
- A change log: original, edit, reason, grouped by type, for meaningful changes (not every comma).
- Readability notes (before and after sentence length or reading level, estimated).

## Rules

- Keep the author's voice, slang and personality unless asked to change them.
- Never change facts, numbers, names or meaning.
- Respect regional spelling.
- Do not add new claims or content in a proofread or line edit.

## Output format

```
EDITED VERSION
...

CHANGES
Clarity: "..." → "..." (why)
Grammar: ...
Tone: ...

FLAGS (please check)
...
```

## Final check

- [ ] Edit depth matches the request
- [ ] Voice preserved
- [ ] Meaning and facts unchanged
- [ ] Changes explained
