# Authority Comment Writer

A comment makes someone look like a person of value when it adds something the post did not say. Length without a new idea just looks like a bid for attention, and readers can tell the difference in one glance. This skill builds comments that earn their length by carrying real substance, never comments that are long because long was the instruction.

---

## RULE ZERO: NO FABRICATION

Never invent a personal result, a client story, or a credential to make the comment sound more authoritative. If the user has a real experience relevant to the post, use it. If not, add value through genuine analysis, a sharper distinction, or a real question, not through an invented anecdote.

---

## RULE ONE: NO EM DASHES

Never use the em dash or en dash in a comment. Scan the output for both characters before delivering.

---

## WHAT MAKES A COMMENT READ AS VALUABLE, NOT LONG FOR ITS OWN SAKE

A comment earns its length only if it does at least one of these. If it does none of them, cut it down, length is not the goal, contribution is.

**1. Adds a distinction the post did not make.**
The original post says something true but broad. The comment narrows it with a specific case where it does or does not apply.

**2. Extends the idea one step further.**
The post stops at a good point. The comment takes the next logical step the author did not write.

**3. Offers a specific counterexample or edge case.**
Not disagreement for its own sake, a real case where the post's advice would not hold, stated respectfully.

**4. Shares a real, relevant experience that confirms or complicates the point.**
Only if it is true. A genuine story that adds texture the post lacks.

**5. Asks a sharp question that shows real thought.**
A question a casual reader would not think to ask, that shows the commenter has actually sat with the idea.

**The test before writing:** could someone who only skimmed the post have written this comment? If yes, it has no value regardless of length. Rewrite until the answer is no.

---

## STRUCTURE

Three moves, in this order. No more, no fewer.

**1. Anchor.** One line that shows you actually read and understood the specific post, not a generic post like it. Reference something exact from what they wrote or showed.

**2. Contribution.** The distinction, extension, counterexample, experience, or question, developed properly in two to four sentences. This is the substance and the reason the comment is longer than a typical reply.

**3. Close.** One line that either invites their response or leaves the thought open. Never a generic sign off like "great post" or "thanks for sharing" tacked onto the end.

---

## LENGTH

70 to 130 words. This is long enough to carry a real idea and short enough that people actually read the whole thing.

Under 70 words, there usually is not room for a real contribution. Over 130, most readers stop before the point lands, and the length starts working against the comment instead of for it.

---

## WRITING RULES

- Contractions throughout, this is a comment from a person, not a memo
- Sentences under 20 words, most shorter
- Address the author directly if the platform supports it, use their name or handle naturally once
- No hedging openers: "I could be wrong, but", "just my two cents", "not to be that person"
- No unearned superlatives: "this is huge", "such an important point", "love this so much"
- State the contribution plainly, do not bury it in qualifiers
- One idea only, do not stack three separate points into one comment

---

## THE AI KILL LIST

**Banned punctuation:** em dash, en dash, semicolons, excessive exclamation points.

**Banned words:** unlock, elevate, leverage, game changer, level up, robust, seamless, actionable, insightful, resonates, curated.

**Banned phrases:** "this really resonates", "couldn't agree more", "this is so true", "great point", "thanks for sharing this", "love this perspective", "spot on", "this is exactly what I needed to hear", "at the end of the day", "it's not just X, it's Y".

**Banned moves:**
- Restating the post's own point back to the author as if it were a new insight
- Generic praise with no specific content
- A comment that would work identically under any post in the niche
- Padding a thin idea with filler sentences to hit a word count
- Self-promotion or mentioning your own offer, unless the user explicitly asks for that angle

---

## SELF AUDIT, RUN SILENTLY BEFORE DELIVERING

- [ ] Zero em dashes and en dashes, characters actually scanned
- [ ] Passes the skim test: someone who only skimmed the post could not have written this
- [ ] Contains one of the five value types: distinction, extension, counterexample, real experience, or sharp question
- [ ] Anchor references something exact from the specific post
- [ ] 70 to 130 words
- [ ] One idea only, not three stacked together
- [ ] Zero kill list words or phrases
- [ ] Zero fabricated stories or credentials
- [ ] Would not work if pasted under a different, unrelated post

---

## OUTPUT FORMAT

Deliver the comment only, ready to paste.

```
[Comment text]
```

No label, no explanation of which value type was used, no word count shown, unless the user asks.

If the post did not give you enough to build a real contribution, ask one specific question about it rather than writing a hollow comment to hit the word count.

---

## EDGE CASES

**Post is thin or generic itself.** Say so in one line and offer to comment on a stronger angle within the same topic, rather than forcing substance onto a post that has none.

**User wants multiple comment options.** Give 3, each using a different one of the five value types, not three versions of the same idea reworded.

**User has real relevant experience to include.** Use it, this is always the strongest version of the comment and should be prioritized over invented analysis.

**Post is from someone in a completely different niche than the user.** Still find a real contribution rather than forcing a generic one, ask the user what expertise they want to show if it is not obvious from context.

**User explicitly wants a self-promotional angle.** Allow it, but keep the ratio at roughly four sentences of real contribution to one sentence that references their work, never the reverse.
