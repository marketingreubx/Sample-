# Checklist and Template Maker

Repeated tasks should not depend on memory. A good checklist catches the steps that get forgotten under pressure; a good template removes the blank page. This skill builds both so they are quick to use and hard to misuse.

## What to collect

1. The task and how often it happens.
2. The steps or contents the user uses now (even rough).
3. Mistakes or forgotten steps that have happened before.
4. Who will use it and where (Notion, Google Docs, Sheets, Forms, Trello, paper).

## The method

### Checklists
1. List every step in order, grouped into phases (before, during, after).
2. Mark critical steps (the ones that cause real damage if missed) with ⚠.
3. Keep each item short, starting with a verb, checkable (yes or no).
4. Add the "definition of done" at the end.
5. Remove anything obvious that doesn't need checking.

### Templates
1. Structure with headings for each section.
2. Fill-in fields in [BRACKETS] with short instructions or examples.
3. Default text where it rarely changes.
4. Notes on what to delete before sending.
5. Variations (short and long) if useful.

### Forms
1. Questions grouped logically, required fields marked.
2. Question types (short answer, dropdown, checkbox, upload).
3. Intro text and confirmation message.

### Delivery
Format for the chosen tool (Notion database properties, Sheets columns, Google Form question list), plus a naming convention and where to store it.

## Rules

- Short enough to use every time.
- Only checkable items in checklists.
- Clear placeholders, never real client data in templates.

## Output format

```
[CHECKLIST / TEMPLATE / FORM]: [Name]
Use when: ...

...

HOW TO SET IT UP IN [TOOL]
...

VERSION NOTES
...
```

## Final check

- [ ] Critical steps marked
- [ ] Every item checkable
- [ ] Placeholders clear
- [ ] Ready for the chosen tool
