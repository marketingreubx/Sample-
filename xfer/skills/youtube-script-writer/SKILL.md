# YouTube Script Writer

On YouTube the title and thumbnail make the promise, and the first 30 seconds prove it was worth the click. After that, retention comes from structure: open loops, steady progress, stories and visual changes. The script is written for the ear, not the eye.

## What to collect

1. Topic, target viewer and the payoff by the end.
2. Video length target and style (talking head, screen recording, documentary, list, tutorial).
3. Channel goal for this video (search traffic, subscribers, leads, product sales).
4. Stories, examples, data and personal experience to include.
5. Call to action (subscribe, lead magnet, product, next video).

## The method

### 1. Packaging first
5 title options (under 60 characters, specific, curiosity plus clarity) and 3 thumbnail concepts (one emotion, under 4 words of text, clear subject). The script must deliver this promise.

### 2. Hook (0:00 to 0:30)
- Restate the promise in the first sentence.
- Show the end result or stakes.
- Preview what is coming without giving it away.
- Credibility in one line.
No long intros, no "before we start, subscribe".

### 3. Body
- Break into 3 to 7 chapters, each with its own mini hook and payoff.
- Open a loop early ("I'll show you the mistake that cost me 3 months at the end").
- Every 60 to 90 seconds: a pattern interrupt (story, example, visual change, question, B-roll).
- Use "you" and concrete examples.
- Mid-roll call to action at around 40% only if it adds value (lead magnet related to the topic).

### 4. Ending
Close the open loops, summarise in one line, then point to one specific next video ("If you want to fix X, watch this next"). No long goodbye.

### 5. Production notes
On-screen text, B-roll list, graphics, chapters with timestamps for the description, and the description itself.

## Rules

- Spoken language: short sentences, contractions, natural rhythm.
- Every section earns its place. Cut anything the viewer could skip.
- Honest payoff. No clickbait the video does not deliver.
- Mark estimated timestamps.

## Output format

```
TITLES (5)
...
THUMBNAILS (3)
...

SCRIPT
[0:00] HOOK
Say: ...
Show: ...

[0:30] CHAPTER 1: ...
...

[END] ...

B-ROLL AND GRAPHICS
...

DESCRIPTION AND CHAPTERS
...
```

## Final check

- [ ] Title, thumbnail and hook make the same promise
- [ ] Hook under 30 seconds
- [ ] Pattern interrupts every 60 to 90 seconds
- [ ] Ending points to a next video
