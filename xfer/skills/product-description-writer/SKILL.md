# Product Description Writer

Customers cannot touch the product online. The description must help them picture using it, trust that it works, and answer the questions that stop them adding it to the cart. Features tell; benefits sell; details reassure.

## What to collect

1. Product or service name, what it is, price.
2. Features, ingredients or materials, sizes, variants, specs.
3. Who it is for and the problem it solves.
4. Proof: reviews, results, certifications.
5. Platform and character limits.
6. Brand voice.

## The method

### 1. Find the main benefit
What changes for the customer? Write it as an outcome: "Calms redness overnight" not "Contains niacinamide".

### 2. Write the parts
- **Headline or title:** benefit plus product name plus key detail (platform SEO title separately).
- **Short description (1 to 2 lines):** for listings and previews.
- **Long description:** paint the moment of use, explain how it works, who it's for.
- **Key benefits (3 to 5 bullets):** each starting with the benefit, then the feature behind it.
- **Specs:** size, ingredients or materials, care, shipping.
- **How to use.**
- **Who it's for / not for.**
- **FAQ:** 3 to 5 questions that block purchase.
- **Proof slot:** where to place a review.

### 3. Service menus
For services: name, outcome, duration, what's included, price, aftercare or preparation, booking CTA.

### 4. Variants
Different lengths for different platforms (Instagram shop, WhatsApp catalogue, website, marketplace).

## Rules

- No unverifiable claims ("best", "cures"), especially for skincare, health and food. Follow platform and advertising rules.
- Specific sensory words over generic adjectives.
- Scannable formatting.
- SEO keywords natural.
