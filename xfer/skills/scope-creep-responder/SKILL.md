# Scope Creep Responder

Small favours add up to unpaid weeks. The fix is not saying no; it is saying "yes, and here is how": as a paid add on, a swap for something else, or a later phase. Said kindly and quickly, clients accept it.

## What to collect

1. The client's request (paste it).
2. The agreed scope (deliverables, revisions, exclusions).
3. The user's rate or add-on prices.
4. The relationship and how often extras have been asked.
5. Whether the user is willing to do a small favour this once.

## The method

### 1. Check against the agreement
Is it in scope, a revision within the allowed rounds, a new deliverable, or a change of direction? Quote the relevant line of the agreement.

### 2. Choose the response
- **Include (rarely):** small, quick, strategic. Say it is a one-off courtesy so it does not become the norm.
- **Quote it:** price and time, needs approval before starting.
- **Swap it:** "We can do this instead of [X] this month."
- **Schedule it:** "Let's add it to next month or phase 2."
- **Decline:** if it does not fit the service, suggest someone else.

### 3. Write the reply
1. Positive opening about the idea.
2. Note that it is outside the current scope, referring to the agreement lightly.
3. Options with price and timing.
4. Easy next step: "Reply 'go ahead' and I'll add it to the invoice."

### 4. Change request template
Description, reason, impact on timeline, cost, approval line.

### 5. Prevent it
Clear exclusions in proposals, revision limits, a change request process explained at kickoff, a rate card of add-ons.

## Rules

- Respond quickly. Delayed responses feel like reluctance.
- Never start extra work before written approval.
- No guilt or lecturing. Friendly and matter-of-fact.
- Give options, not just a price.

## Output format

```
WHAT THIS IS
In scope / Revision / New work / Direction change
Agreement says: "..."

RECOMMENDED RESPONSE
...

REPLY
...

CHANGE REQUEST
Item ... | Price ... | Time ... | Approve by replying ...

PREVENT IT NEXT TIME
...
```

## Final check

- [ ] Checked against the agreement
- [ ] Options offered (quote, swap, schedule)
- [ ] Written approval required
- [ ] Friendly tone
