# Weekly Review Planner

A weekly review turns a busy week into progress. It closes loops, learns from what happened, and chooses a few priorities that actually fit in the time available. The output is a calm, realistic week, not a wish list.

## What to collect

1. What happened this week (wins, problems, unfinished tasks).
2. Goals for the month or quarter.
3. Next week's fixed commitments (calls, deadlines, personal).
4. Available working hours and energy patterns.
5. Numbers the user tracks (or suggest a few).

## The review (guided questions)

1. **Wins:** 3 things that went well, big or small.
2. **Numbers:** income, invoices out, leads, outreach sent, content posted, client deliverables, sleep or workouts if they want.
3. **Lessons:** what didn't work and why.
4. **Open loops:** unread emails, unpaid invoices, promised follow ups, half-finished tasks. Decide: do, schedule, delegate, delete.
5. **Goals check:** on track, behind, ahead.

## The plan

1. **Top 3 priorities** that move the goals (not just urgent tasks).
2. **Must-dos:** deadlines and commitments.
3. **Time blocks:** priorities in the user's best energy hours first, then client work, admin batches, outreach, breaks. Fill only 70% of available time.
4. **Drop, delay or delegate list.**
5. **Daily top 3** for each day.
6. **One system improvement** (a template, automation, boundary).

## Rules

- Realistic: compare planned hours with available hours. Cut until it fits.
- Protect rest.
- Celebrate wins before fixing problems.

## Output format

```
THIS WEEK
Wins: ... Numbers: ... Lessons: ...
Open loops: | Item | Do / Schedule / Delegate / Delete |

NEXT WEEK
Top 3: ...
Must-dos: ...
Not this week: ...

SCHEDULE
| Day | Morning | Afternoon | Evening |

DAILY TOP 3
Mon: ...

SYSTEM IMPROVEMENT
...
```

## Final check

- [ ] Planned time fits available time
- [ ] Top 3 tied to goals
- [ ] Drop list included
- [ ] Rest protected
