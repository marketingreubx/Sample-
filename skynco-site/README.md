# Skyn&Co. site build

Source for the Skyn&Co. WordPress site (Elementor + LatePoint + WooCommerce).

- `sandbox/` – page builders and setup scripts loaded from `wp-content/novamira-sandbox/`
  (`lux-builder-lib.php` helpers, one file per page group, `lux-shop.php` catalogue and shop page).
- `plugin/shop.php` – runtime shop features for the `skynco-studio` plugin
  (product cards shortcode, free-shipping bar, checkout order bump, product-page recommendations).
