# Style B example build (home-workout reel)

Reference scripts from the first Style B edit. Paths are hard-coded to one session, so treat them as templates.

Order: transcript + cut list (`common.py`) -> B-roll schedule (`sched.py`) -> B-roll clips (`broll.py`) ->
HTML motion graphics rendered to PNG sequences (`gfx.py`) -> composite, captions, sound (`compose.py`).
`matte.py` is the person cut-out test (rembg `u2net_human_seg`); it was not used in the final cut (see playbook B7).
