# Viral Format Library

Name the original's format from this list (or "Hybrid: A + B"). Each format has a fixed skeleton; the remix must keep it.

## Hook types (first 1–2 seconds)
| Type | Pattern | Example |
|---|---|---|
| Call-out | "If you [do X], stop." / "[Audience], listen." | "Abuja girls, stop picking your blackheads." |
| Mistake | "This is the step you're missing" / "You're doing X wrong" | "Your cleanser can't do this." |
| Myth bust | "[Common belief] is a lie." | "Shaving does NOT make hair grow back thicker." |
| Result-first | Show the after, then "here's how" | "Week 1 vs week 8 🤯" |
| Curiosity | "Watch what happens when…" / "Sound on 🔊" | "Watch the dead skin come off." |
| POV / relatable | "POV: [situation the audience lives]" | "POV: client says she only used her sister's cream small" |
| Story | "She almost gave up on…" / "I refused to…" | "I refused to give this client a facial." |
| Number/list | "3 things…" / "The only 2…" | "3 things I see when you walk in with dark spots." |
| Reaction | Someone's genuine reaction | "Her first wax 😭" |
| Comparison | "X vs Y" | "Toning cream vs real treatment." |

## Formats and their skeletons

1. **Satisfying / ASMR process** — Hook text ("Sound on 🔊") → 3–6 close-up process shots with real sound → reveal/after → no talking. 7–30s.
2. **Before → After transformation** — After flash or "before" with tension → quick process montage → slow reveal → caption CTA. 8–25s.
3. **Myth bust / education to camera** — Myth hook → "here's the truth" (1 reason) → proof/demo → "so do this instead" → comment-keyword CTA. 15–45s.
4. **Listicle tips** — "N things…" hook → N fast tips (one line + one visual each) → last tip is strongest → CTA. Keep N identical in remix.
5. **POV / relatable skit** — POV text on screen → one situation → one reaction (face, trending audio) → punchline. No CTA or soft CTA. 5–15s. Drives shares.
6. **Reaction / first-timer** — Nervous setup → the moment → genuine reaction → result → their quote. 10–40s.
7. **Day in the life / BTS** — Time-stamped or fast-cut routine → one surprising moment → ending line. 20–60s.
8. **Storytime** — Story hook → setup → conflict → turn → lesson/result → CTA. 30–90s.
9. **Green-screen / reacting to a post** — Creator over a screenshot/video → hot take → correct info → CTA.
10. **Progress series** — "Week N" label → same angle shot → comparison → "follow for week N+1".
11. **Celebrity / influencer visit** — Guest arrives → treatment moments → guest's reaction/review in their voice → collab post. Usually posted as a collab.
12. **Trend / audio template** — Uses a trending sound's fixed beats (text changes on each beat). Remix = same audio, same beat count, niche text.
13. **Comment-keyword lead magnet** — Any of the above ending with "Comment [WORD] and I'll send you…". Keep the mechanic; change the word to the user's offer.

## Translating across niches (TRANSLATE mode)

Find the emotional equivalent, not the literal one:
| Original idea | Esthetician equivalent | Social media manager equivalent |
|---|---|---|
| Gym form check | "Rate my skincare routine" | "Rate my Instagram bio" |
| Cooking hack | Skincare hack (ice roller, layering order) | Content hack (batching, hook formula) |
| Car detailing ASMR | Extraction / dermaplaning ASMR | Feed redesign before/after screen recording |
| Haircut transformation | Facial glow transformation | Account growth before/after (insights screen) |
| "Things my clients say" (any service) | Things clients say on the facial bed | Things clients say about posting |
| Price breakdown | "What ₦X facial actually includes" | "What $3K/month management includes" |
