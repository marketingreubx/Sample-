# Edit Checklist (run on every post)

1. **Cut 20%.** Delete "really", "very", "just", "actually", "in order to", "the fact that", "I think".
2. **First 7 words** must create tension or a claim. If they're setup, move the punch earlier.
3. **One idea.** Remove any second idea.
4. **Contrast present?** If not, add the opposite (A vs B, before vs after, belief vs truth).
5. **Concrete?** Swap one abstract word for a number, a named moment or the audience's own phrase.
6. **Rhythm.** Read it aloud. Short → short → slightly longer ending, or three equal beats. End on the strongest word.
7. **Line breaks** only where the reader should pause. One-liners stay on one line.
8. **Quote test.** Could someone screenshot it with no context and still get it? If not, simplify.
9. **No AI tells.** No "Here's the thing", "Let that sink in", "In today's fast-paced world", "game-changer", "unlock", "elevate", "delve", stacked em-dashes, or a colon before every list.
10. **No fake proof.** Every number or story is the user's own or marked `[your number]`.
11. **Not a copy.** Shares no sentence with a source tweet.
12. **Niche check.** Does it name the audience's world (clients, DMs, facials, bookings) while keeping a universal truth?
